# CSS Frameworks CA

This is the course assignment for the CSS Frameworks course, which has three pages styled with Bootstrap.
These being: Main feed (index.html while logged in), profile page (profile.html) and login page (login.html).

## Getting started

```bash
npm install
```

### Available scripts

**For compiling:**

```bash
npm run build
```

**For seeing changes for each file save:**

```bash
npm run watch
```
## Technologies used

- JavaScript
- HTML
- Bootstrap v5
- Sass
