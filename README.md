# CSS Frameworks CA

![image](https://i.imghippo.com/files/Tdu6746ZN.png)

This is the upgraded and fixed CA for CSSFrameworks, for the course Portfolio 2. The original site had three pages styled with Bootstrap.
These being: Main feed (index.html while logged in), profile page (profile.html) and login page (login.html). The updated version is styled using TailwindCSS v4, and has improved UX as well as improved functions. Users can now delete their posts and visit other users through both the homepage and when viewing posts.

## Getting started

1. Clone the repo:

```bash
gh repo clone GustavBoe/JavaScript2Fall25_StillApp
```

2. Install the dependencies:

```
npm install
```

### Running

To run the app, run the following commands:

```bash
npm run dev
```
